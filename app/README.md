# Приложение «Мой проездной»

Приложение для ОС Аврора (Qt5/QML, Sailfish Silica). Показывает баланс,
данные о поездках и проездных при поднесении транспортной карты
к телефону. Пока поддерживается только карта «Подорожник»
(Санкт-Петербург).

## Структура

- `src/main.cpp` — точка входа (шаблон `auroraapp`), публикует `cardReader`
  в контекст QML.
- `src/cardreader.{h,cpp}` — работа с nfcd по D-Bus (`org.sailfishos.nfc.*`):
  слежение за метками адаптера, авторизация секторов MIFARE Classic и чтение
  блоков через `Tag.Transceive()`.
- `src/podorozhnik.{h,cpp}` — чистый парсинг данных карты (номер, баланс,
  форматирование), ключи секторов.
- `qml/` — корневой QML, главная страница и обложка.
- `translations/` — переводы (исходные строки — русские, базовый `.ts` —
  английский).
- `rpm/` — spec-файл пакета; `.desktop` — разрешение `NFC`.

## Поведение

Приложение должно быть открыто (или висеть в фоне). При поднесении карты
экран переходит в «Чтение карты…», затем показывает баланс, номер карты
и UID. Ошибки (карта не MIFARE Classic, ключ не подошёл, карта убрана рано)
показываются с подсказкой повторить.

Автозапуск по касанию не реализован: системный обработчик nfcd умеет
запускать приложения только по NDEF-типам, а Подорожник NDEF не содержит.
